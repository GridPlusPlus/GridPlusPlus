# 定義物件行為

GridObject 保存位置、素材、tag 和顯示狀態等共通資料。物件在遊戲中如何行動，則由更新與碰撞行為決定。更新行為每幀執行，可讀取輸入、時間與其他遊戲狀態；碰撞行為在兩個可見物件位於同一個有效格子時執行。

打地鼠把 `UpdateMole` 交給 `Spawn()`，由 Engine 在每幀回呼。這種函式式 API 會在內部建立 `CallbackGridObject`，適合以普通函式完成行為的物件。本章會完整說明 callback 的參數與執行方式，再加入玩家與豆子，觀察同格碰撞的規則。

繪製也屬於物件行為，但多數物件可以直接使用 GridObject 的預設 `Render()`。素材、基本圖形與自訂繪製集中在第 6 章說明。

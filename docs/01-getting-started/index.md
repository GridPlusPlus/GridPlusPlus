# 開始使用

這一章結束時，你的電腦會跳出一個視窗，裡面有一隻屬於你的小精靈：

![第一個程式的畫面：黑色視窗中央有一隻黃色小精靈，左上角寫著 Hello, Grid++!](../images/tutorial/hello.png)

要走到這一步，我們會一起完成五件事。每一件事都只要**照著做、把指令複製貼上**就好，不需要先看懂它們。

| | 要做的事 | 大約時間 |
|---|---|---|
| 1 | [準備電腦](01-prepare.md)：打開「終端機」，安裝寫程式要用的工具 | 20–40 分鐘 |
| 2 | [安裝 raylib](02-install-raylib.md)：讓程式可以開視窗、畫圖 | 10 分鐘 |
| 3 | [取得你的專案](03-get-project.md)：登入 Gitea，拿到 Pac-Man 專案 | 10 分鐘 |
| 4 | [執行第一個程式](04-first-run.md)：看到小精靈出現 | 5 分鐘 |
| 5 | [把作品存到 Gitea](05-save.md)：寫好的程式不會不見 | 5 分鐘 |

前兩件事每台電腦只要做一次；之後每次寫程式，就只會用到第 4、5 件事。

!!! tip "卡住了怎麼辦？"

    每一頁最後都有「常見問題」。如果還是解決不了，把**終端機裡的錯誤訊息整段複製**下來，連同你做到哪一步，一起問助教。只說「不能跑」的話，助教也很難幫你喔。

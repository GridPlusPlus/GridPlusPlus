# 開始使用

這一章會帶你準備 Grid++ 所需的開發環境，並執行第一個 Grid++ 程式。完成後，你應該能在電腦上開啟一個遊戲視窗，看到由 Grid++ 建立的 8×8 空白網格。

Grid++ 使用 C++17，並以 raylib 處理視窗、鍵盤與滑鼠輸入、圖片及其他底層功能，因此開始使用 Grid++ 前，需要先讓 C++ 編譯器能夠使用 raylib。接下來會先完成這項設定，再建立一個最小的 Grid++ 程式，以確認整個開發環境可以正常運作。

這一章不需要先理解遊戲迴圈、物件導向或 Grid++ 的內部設計。看到程式中還不熟悉的名稱時，可以先按照步驟完成程式；後面的教學會在實際需要這些功能時，再說明它們的用途與彼此的關係。

## 這一章會完成什麼？

1. 安裝並測試 raylib
2. 準備 Grid++ 專案
3. 編譯並執行第一個 Grid++ 程式
4. 確認畫面顯示 8×8 網格

完成以上步驟後，就可以開始製作第一個遊戲。

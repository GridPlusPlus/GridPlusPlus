# Grid++

Grid++ 是用來建立網格遊戲的 C++17 函式庫。遊戲畫面被分成固定大小的格子；玩家、敵人和道具以整數座標位於格子中，Grid++ 負責視窗、主迴圈、物件更新、同格碰撞與繪製。它建立在 [raylib](https://www.raylib.com/) 上，並以只需引入標頭檔的形式提供。

本文件以兩個可執行專案介紹 Grid++。第 1 章先確認開發環境可用；第 2 章用小型範例建立網格座標、物件、每幀更新與畫面資訊的基本模型；第 3 章再用普通函式逐步完成打地鼠。後續章節深入行為與物件狀態，第 7 章則以 Pacman 組合迷宮、素材、碰撞、Overlay 與遊戲狀態。

讀者應已熟悉 C/C++ 語言之變數、條件判斷、迴圈、函式、陣列與指標。本文件會說明 Grid++ 如何使用函式指標、繼承與虛擬函式，但不重複教授基礎 C++ 語法。

教學中的公開 API 會連結至自動產生的 [API 參考](api/index.md)。API 參考適合查詢完整簽名、參數與例外；編號章節說明各項功能在遊戲中的用途與組合方式。

## 如何閱讀程式碼

標題為 `main.cpp` 的程式碼區塊，是該步驟可以直接編譯的完整檔案；標題含有「節錄」時，則表示它來自附近已指明的函式或類別，必須放回該位置理解。只有函式簽名或參數順序的短區塊會明確標成「示意」，不應當成完整程式貼入。第 3 章採用逐步實作形式，每個里程碑都提供完整檔案；第 7 章則導讀專案中已經完成的 Pacman，因此應先執行完成品，再對照節錄閱讀。

文件第一次使用必要的英文術語時會附上中文意思，後續則優先使用中文；`GridObject`、`OnUpdate()`、tag 與 z-index 等程式識別字保留原名，以便直接對照 API 與原始碼。

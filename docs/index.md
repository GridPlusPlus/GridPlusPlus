# Grid++

Grid++ 是一個用來製作**網格遊戲**的 C++ 函式庫。

在 Grid++ 中，遊戲畫面被分成一格一格。玩家、敵人和道具只需要記住自己位在哪一格，就可以進行移動、碰撞和互動。

Grid++ 會幫你處理遊戲視窗、畫面更新和許多共通工作，讓你可以把重點放在**遊戲規則本身**。

![使用 Grid++ 製作的 Pac-Man](images/preview.png)

## 第一次使用 Grid++？

建議從「開始使用」開始。

你會先確認開發環境可以使用 Grid++，接著執行第一個簡單的網格程式。之後的教學會一步一步加入物件、移動、碰撞、分數和圖片，最後組成完整的遊戲。

[開始使用](01-getting-started/index.md){ .md-button .md-button--primary }

## 可以用 Grid++ 做什麼？

學習後，你會知道如何：

* 在網格中加入玩家、敵人和其他物件
* 使用鍵盤或滑鼠控制遊戲
* 讓物件移動並互相碰撞
* 顯示分數、文字和按鈕
* 使用圖片與基本圖形繪製遊戲畫面
* 管理遊戲開始、進行、勝利與失敗等狀態

文件中也提供完整的打地鼠與 Pac-Man 範例，可以直接執行並修改。

## 需要具備什麼基礎？

這份文件假設你已經學過基本的 C 或 C++，例如：

* 變數
* `if` 條件判斷
* 迴圈
* 函式
* 陣列

不需要事先學過遊戲程式設計，也不需要會使用指標、`new`、`delete`、繼承或樣板（template）。Grid++ 的遊戲行為全部寫成普通函式，物件的建立與釋放由函式庫負責；遇到 Grid++ 使用到的新概念時，後面的教學會再逐步介紹。

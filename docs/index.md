# Grid++

**用 C++ 做出你自己的遊戲。**

Grid++ 把遊戲畫面切成一格一格。玩家、敵人和道具只要知道自己在哪一格，就能移動、碰撞和互動；開視窗、畫圖這些麻煩事都交給 Grid++，你只要專心想**遊戲規則**。

![使用 Grid++ 製作的 Pac-Man](images/preview.png)

## 從這裡開始

這份文件從零開始帶你：

1. **[開始使用](01-getting-started/index.md)**：準備電腦，讓第一隻小精靈出現在畫面上。
2. **[從零做出 Pac-Man](02-pacman-tutorial/index.md)**：分成六步，做出會追人的鬼和吃豆子的小精靈。每一步做完都能玩！

不需要先會 Git，也不需要知道怎麼編譯程式，需要的指令都可以直接複製貼上。

## 需要什麼基礎？

學過一點 C 或 C++（變數、`if`、迴圈、函式、陣列）會比較輕鬆。還沒學過也沒關係，先跟著做、玩玩看，再回頭弄懂每一行在做什麼。

遊戲程式設計的經驗、指標、`new`、`delete`、繼承或樣板（template）都**不需要**。

# 素材與繪製

GridObject 的行為決定遊戲規則，`Render()` 將物件目前的狀態轉換成畫面。預設 Render 讀取物件的素材名稱、方向與 tint，要求 Engine 在物件所在格繪製圖片。使用同一素材的兩個物件仍可有不同座標、方向、顏色與 z-index。

Grid++ 提供三種畫面來源。素材包適合角色與場景圖片；`GridShapes.h` 提供不需外部檔案的方形、圓形、三角形、五邊形和五芒星；覆寫 `Render()` 則可直接呼叫 raylib，建立完全自訂的畫面。三種方式都沿用 GridObject 的生命週期、座標和碰撞規則。

打地鼠先使用缺少素材時的紅色 fallback 方塊，讓遊戲規則可以獨立完成。本章會從這個方塊開始，加入正式素材或基本圖形，最後整理顯示狀態與繪製順序。

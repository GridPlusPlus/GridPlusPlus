# 素材與繪製

GridObject 的行為決定遊戲規則，`Render()` 將物件目前的狀態轉換成畫面。預設 `Render()` 讀取物件的素材名稱、方向與色彩調整值，要求 Engine 在物件所在格繪製圖片；即使兩個物件使用相同素材，仍可各自擁有不同的座標、方向、顏色與繪製層級。

Grid++ 提供三種畫面來源。素材包適合角色與場景圖片；`GridShapes.h` 提供不需外部檔案的方形、圓形、三角形、五邊形和五芒星；覆寫 `Render()` 則可直接呼叫 raylib，建立完全自訂的畫面。三種方式都沿用 GridObject 的生命週期、座標和碰撞規則。

打地鼠先使用找不到素材時的紅色替代方塊，讓遊戲規則可以獨立完成。本章會從這個方塊開始，加入正式素材或基本圖形，最後整理顯示狀態與繪製順序。

## 完成本章後

- 能把 32×32 PNG 圖片轉成素材包並以名稱載入。
- 能判斷何時使用素材、內建圖形或自訂 `Render()`。
- 能利用顯示狀態、色彩調整與 z-index 控制畫面，而不改變遊戲規則。
